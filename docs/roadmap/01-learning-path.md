# Learning Path

## Phase 1 – Linux Foundations (Modules 00–08)

Work through these in order. Each module builds on the previous.

```
Module 00 – Prerequisites
    ↓
Module 01 – Linux Navigation
    ↓
Module 02 – Files & Permissions
    ↓
Module 03 – Text Processing
    ↓
Module 04 – Users & sudo
    ↓
Module 05 – Processes & System
    ↓
Module 06 – Networking Basics
    ↓
Module 07 – Package Management
    ↓
Module 08 – Shell Scripting
    ↓
[Checkpoint 1 – Linux Basics]
```

**After Phase 1 you can:** navigate the filesystem, manage files and permissions, process logs, write simple scripts, and manage packages on Ubuntu/Debian/Fedora/macOS.

## Phase 2 – Container Foundations (Modules 09–11)

```
Module 09 – Container Basics
    ↓
Module 10 – Dockerfile & Build
    ↓
Module 11 – Running Containers
    ↓
[Checkpoint 2 – Container Basics]
```

**After Phase 2 you can:** explain containers, write Dockerfiles, build images, and run containers with the right flags.

## Phase 3 – Advanced Docker (Modules 12–15)

```
Module 12 – Volumes & Networking
    ↓
Module 13 – Docker Compose
    ↓
Module 14 – Registry & Distribution
    ↓
Module 15 – Production Patterns
    ↓
[Checkpoint 3 – Production-Ready]
```

**After Phase 3 you can:** design multi-service applications, push images to registries, and apply production security patterns.
