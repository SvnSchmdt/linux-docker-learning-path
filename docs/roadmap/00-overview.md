# Overview

## What this learning path covers

The Linux & Docker Learning Path takes you from zero to confident in two foundational technologies:

1. **Linux** — the operating system underneath virtually every server, container, and cloud workload
2. **Docker** — the standard toolchain for building, shipping, and running container-based applications

## Who should use this

| Profile | Starting point |
|---------|---------------|
| Complete beginner (no terminal experience) | Module 00 – Prerequisites |
| Linux basics known, new to containers | Module 09 – Container Basics |
| Know Docker, want production patterns | Module 13 – Docker Compose |

## Learning objectives

After completing this learning path, you will be able to:

**Linux**
- Navigate the Linux filesystem confidently
- Manage file permissions and user accounts
- Process text files and build pipelines with shell tools
- Write basic shell scripts for automation
- Manage packages and system services

**Docker**
- Explain what containers are and how they differ from VMs
- Write Dockerfiles and build production-ready images
- Run, debug, and manage containers
- Design multi-service applications with Docker Compose
- Apply security and efficiency patterns for production
