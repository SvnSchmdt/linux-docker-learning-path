# Überblick

## Was dieser Lernpfad abdeckt

Der Linux & Docker Learning Path bringt dich von null zu sicher in zwei grundlegenden Technologien:

1. **Linux** — das Betriebssystem unter nahezu jedem Server, Container und Cloud-Workload
2. **Docker** — die Standard-Toolchain zum Bauen, Ausliefern und Betreiben von container-basierten Anwendungen

## Für wen ist das?

| Profil | Einstiegspunkt |
|--------|----------------|
| Kompletter Einsteiger (kein Terminal-Erfahrung) | Modul 00 – Voraussetzungen |
| Linux-Grundlagen bekannt, neu bei Containern | Modul 09 – Container-Grundlagen |
| Docker bekannt, Production Patterns gesucht | Modul 13 – Docker Compose |

## Lernziele

Nach Abschluss dieses Lernpfads kannst du:

**Linux**
- Das Linux-Dateisystem sicher navigieren
- Dateiberechtigungen und Benutzerkonten verwalten
- Textdateien verarbeiten und Pipelines mit Shell-Tools bauen
- Einfache Shell-Scripts für Automatisierung schreiben
- Pakete und System-Services verwalten

**Docker**
- Erklären, was Container sind und wie sie sich von VMs unterscheiden
- Dockerfiles schreiben und produktionsreife Images bauen
- Container starten, debuggen und verwalten
- Multi-Service-Anwendungen mit Docker Compose entwerfen
- Sicherheits- und Effizienz-Patterns für die Produktion anwenden
