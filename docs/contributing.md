# Contributing

Thank you for wanting to contribute to the Linux & Docker Learning Path! Please see the [CONTRIBUTING guide](https://github.com/svnschmdt/linux-docker-learning-path/blob/main/CONTRIBUTING.md) in the repository root for full guidelines.

## Quick reference

- New content always needs **both language versions** (EN + DE)
- All shell commands must be tested locally before writing
- `mkdocs build --strict` must pass after every change
- No secrets, tokens, or passwords in the repository

## Commit conventions

```
add:    New content (module, lab, exercise)
fix:    Bug fix (wrong command, wrong output)
update: Update existing content
docs:   Documentation changes
```
