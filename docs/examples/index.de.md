# Examples

Fertige Beispieldateien. Kopieren, anpassen und darauf aufbauen.

| Datei | Beschreibung |
|-------|-------------|
| [Dockerfile.simple](Dockerfile.simple) | Einfaches nginx-Image mit einer benutzerdefinierten HTML-Seite |
| [Dockerfile.multistage](Dockerfile.multistage) | Node.js Multi-Stage Build |
| [docker-compose.example.yml](docker-compose.example.yml) | Full-Stack-App mit DB, Redis und Healthchecks |
| [dockerignore.example](dockerignore.example) | Umfassendes .dockerignore für die meisten Projekte |
| [secret.example.env](secret.example.env) | Vorlage für .env-Dateien — nur Dummy-Werte |

> [!IMPORTANT]
> `secret.example.env` enthält nur Dummy-Werte. **Niemals echte Zugangsdaten committen.** Als `.env` kopieren und lokal mit echten Werten füllen.
