# Examples

Ready-to-use example files. Copy, adapt, and build on them.

| File | Description |
|------|-------------|
| [Dockerfile.simple](Dockerfile.simple) | Simple nginx image with a custom HTML page |
| [Dockerfile.multistage](Dockerfile.multistage) | Node.js multi-stage build |
| [docker-compose.example.yml](docker-compose.example.yml) | Full-stack app with DB, Redis, and health checks |
| [dockerignore.example](dockerignore.example) | Comprehensive .dockerignore for most projects |
| [secret.example.env](secret.example.env) | Template for .env files — dummy values only |

> [!IMPORTANT]
> `secret.example.env` contains only dummy values. **Never commit real credentials.** Copy it to `.env` and fill in real values locally.
