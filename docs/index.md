# Linux & Docker Learning Path

Welcome to the **Linux & Docker Learning Path** — a practical, hands-on guide from your first terminal command to production-ready container workflows.

## Who is this for?

This learning path targets **beginners to junior developers and DevOps engineers** who want to learn Linux and container technology systematically — as preparation for Kubernetes or cloud work in general. No prior experience required.

## What you'll learn

=== "Linux Basics"
    - Navigate the filesystem like a pro
    - Understand file permissions and user management
    - Process text and automate tasks with shell scripts
    - Manage packages, processes, and system services

=== "Docker & Containers"
    - Understand what containers really are (and aren't)
    - Write Dockerfiles and build images
    - Run, inspect, and manage containers
    - Compose multi-service applications
    - Apply production-ready patterns
