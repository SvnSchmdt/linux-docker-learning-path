# Labs

Jedes Lab hat ein klares Ziel, Schritt-für-Schritt-Anweisungen mit erwarteter Ausgabe, einen Validierungsabschnitt zur Bestätigung des Erfolgs und einen Cleanup-Abschnitt, damit keine Ressourcen zurückbleiben.
