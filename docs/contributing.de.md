# Beitragen

Danke, dass du zum Linux & Docker Learning Path beitragen möchtest! Die vollständige Anleitung findest du im [CONTRIBUTING-Leitfaden](https://github.com/svnschmdt/linux-docker-learning-path/blob/main/CONTRIBUTING.md) im Repository-Root.

## Kurzreferenz

- Neue Inhalte brauchen immer **beide Sprachversionen** (EN + DE)
- Alle Shell-Befehle lokal testen, bevor man sie aufschreibt
- `mkdocs build --strict` muss nach jeder Änderung durchlaufen
- Keine Secrets, Tokens oder Passwörter im Repository

## Commit-Konventionen

```
add:    Neuer Inhalt (Modul, Lab, Exercise)
fix:    Fehlerkorrektur (falscher Befehl, falsche Ausgabe)
update: Bestehenden Inhalt aktualisieren
docs:   Dokumentationsänderungen
```
