# Glossary

| Term | Definition |
|------|-----------|
| **Alpine** | A minimal Linux distribution (~5 MB) commonly used as Docker base image |
| **Bind Mount** | Mounting a host directory into a container (`-v /host/path:/container/path`) |
| **cgroups** | Linux kernel feature that limits resource usage (CPU, memory) for a group of processes |
| **CMD** | Dockerfile instruction: the default command run when a container starts |
| **Container** | An isolated process running on the host kernel using namespaces and cgroups |
| **Context (build context)** | The directory sent to the Docker daemon when building an image |
| **distroless** | Docker base images with no shell, package manager, or OS utilities — minimal attack surface |
| **ENTRYPOINT** | Dockerfile instruction: the fixed executable; CMD becomes its arguments |
| **Ephemeral** | Temporary; containers are ephemeral — when removed, data inside is lost |
| **FROM** | First Dockerfile instruction; specifies the base image |
| **Healthcheck** | A command Docker runs to test if a container is working correctly |
| **Image** | A read-only template used to create containers |
| **Layer** | Each Dockerfile instruction creates a new layer; layers are cached independently |
| **Namespace** | Linux kernel feature that provides isolation (PID, network, filesystem, etc.) |
| **Named Volume** | A Docker-managed volume identified by name rather than host path |
| **OCI** | Open Container Initiative; defines standards for container images and runtimes |
| **Pipe (`\|`)** | Connects stdout of one command to stdin of the next |
| **Redirect (`>`)** | Sends stdout to a file (overwrites); `>>` appends |
| **Registry** | A server that stores and distributes Docker images (Docker Hub, GHCR) |
| **RUN** | Dockerfile instruction; executes a command during the image build |
| **Service** | A named component in a `docker-compose.yml` file |
| **Shell** | A command-line interpreter (bash, zsh) |
| **Symlink** | A file that points to another file or directory (`ln -s`) |
| **Tag** | A label on a Docker image indicating its version (e.g., `nginx:alpine`) |
| **Volume** | A mechanism for persisting data generated by and used by Docker containers |
| **WORKDIR** | Dockerfile instruction; sets the working directory for subsequent instructions |
